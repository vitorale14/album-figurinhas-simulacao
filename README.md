# Álbum de Figurinhas – Simulação

Este projeto é uma simulação em PHP do problema do colecionador de figurinhas.
O objetivo é simular a compra de pacotes de figurinhas e a inserção das figurinhas
em um álbum, evitando repetições.

## Como funciona

- Cada pacote contém várias figurinhas aleatórias
- O pacote pode ter figurinhas repetidas
- O álbum guarda apenas figurinhas únicas
- A simulação mostra a diferença entre pacote e álbum

## Arquivo principal

- `main.php` — script principal da simulação

## Como executar

### Opção 1: Terminal
Certifique-se de ter o PHP instalado e execute:

```bash
php main.php
